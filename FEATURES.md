# Markdown BBCode Features

## Documents

| Feature | Behaviour |
| --- | --- |
| Local Markdown | Default .md; .markdown, .mdbbcode and auto-detected non-BBCode .txt files supported directly in tabs (supporting middle-click `auxclick` to close tabs safely). |
| Autosave | Saves only Markdown; existing BBCode companions are untouched. |
| Optional YAML | Arbitrary frontmatter retained; legacy export target dropdown remains available. |
| On-Demand BBCode | Copy or explicit `.bbcode`/`.txt` Export with selectable `Nexus | Steam` dialect (persisted globally and respected by legacy YAML targets), Nexus paragraph/heading blank-line separation with glued `[list][*]...` openings (`\n` after `[/list]`) and single-newline `[hr]`, `[quote]`/callout and `[code]` blocks (preserving extra intentional blank lines), Steam guide tags (`[h1]`–`[h3]`, `[strike]`, `[olist]`, `› ` flattened lists, native `[table]`, `[hr][/hr]`, `[noparse]`, bare embeds and glued `[code]`), loss review, replacement confirmation and revision checks. |
| One-Time Import | Auto-detects Nexus and Steam BBCode tags in opened `.txt` files (alongside `.bbcode` files), reconstructs headings, tables, flattened `› ` lists, inline `[code]` and `[noparse]`, reviews unsupported formatting and protects originals. |
| Recovery | Open tabs, unnamed drafts, preferences, window bounds (with off-screen startup rescue) and legacy imports persist in `portable-data` (portable) or `%APPDATA%\Markdown BBCode` (installed). |
| Auto-Updater | Silent startup check plus footer manual check and one-click header `Update` button for both NSIS installed and signed portable builds, flushing clean files and blocking on unresolved conflicts before restarting or swapping. |
| Conflict Protection | Clean external updates and non-intersecting line additions/removals auto-sync with a `View Diff` / `Revert Sync` review banner; intersecting conflicts open a Unified / Side-by-Side Diff View with per-hunk `Keep Mine` / `Use Disk` / `Keep Both` merging alongside `Load Disk Version`, `Keep My Edits`, and `Save As`. Externally deleted files expose `Review Missing File` and `Close Tab` actions; clean missing tabs close or quit directly without blocking shutdown, while unsaved edits prompt with `File Missing On Disk` (`Keep My Edits`, `Save As`, `Close Without Saving`, `Cancel`). Other save failures prevent closing. |

## Limits

Publishing, image uploads and managed local attachments are deferred. BBCode export warns when reducing unsupported elements for the chosen dialect (such as tasks, tables or callouts on Nexus, or colors, center blocks, `h4`–`h6`, tasks, callouts, footnotes or math on Steam). Unsupported syntax remains editable in Source/Hybrid and may block conversion. Visual edits normalize Markdown; mode/tab changes reset undo. Adjacent compatible lists follow Markdown merging rules. Final Nexus or Steam rendering needs a site check.

## Hybrid Spacing And Icon Controls

Real top-level blank lines are individual editable blocks; content blocks have no extra trailing editor rows. Gutter actions do not add vertical space. Blank rows can be edited, duplicated, deleted or moved, with undo. Internal container spacing is preserved.

File and formatting actions use locally bundled Material Symbols Rounded icons with hover and keyboard-focus tooltips. Icons work offline, preserve active styles and retain accessible names. Modes, dropdowns and confirmation actions remain text-labelled.

Block-type and block-action entries in Turn Into, Block Actions, Insert and slash menus show matching icons alongside their text, including distinct Heading 1, 2 and 3 symbols.
